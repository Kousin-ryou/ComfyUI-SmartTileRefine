# Changelog

## 1.0.0 — 2026-11-11

First public release / 首次公开发布。

- One IMAGE output with standard MODEL, VAE and CONDITIONING inputs.
- Custom 1–8 columns and rows, exact integer coverage and per-side percentage extension.
- Independent tiles or S-shaped sequential context.
- Automatic optional model upscaling, standard VAE encode/decode and native sampling.
- Bounded low-frequency color correction and separately normalized frequency blending.
- In-node preview: continuous white grid, blue hover extension, temporary adjustment highlight, no placeholder text.
- Free node resizing, Chinese/English labels and one overall progress indicator.
- Reproducible original demonstrations, illustrated documentation and CPU regression checks.
